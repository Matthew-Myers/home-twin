# Design rules for concept checks

These are common planning numbers, so the write-up can say *how much* room something leaves. Each
one is marked **code** (a typical US residential code minimum: local code decides), **guideline**
(widely used planning guidance, e.g. NKBA) or **taste**. When you quote one, say which it is. Check
local code before anything is built. Structural, gas, electrical and plumbing changes need the
right professional.

| What | Number | Kind |
|---|---|---|
| Work aisle, one cook | 1.07 m / 42 in | guideline |
| Work aisle, two cooks | 1.22 m / 48 in | guideline |
| Walkway (no work at it) | 0.91 m / 36 in | guideline |
| Behind a seated diner, no traffic | 0.81 m / 32 in | guideline |
| Behind a seated diner, someone edging past | 0.91 m / 36 in | guideline |
| Behind a seated diner, a walkway | 1.12 m / 44 in | guideline |
| Counter seating width per person | 0.61 m / 24 in | guideline |
| Knee space: table 30 in / counter 36 in / bar 42 in | 0.46 / 0.38 / 0.30 m (18 / 15 / 12 in) | guideline |
| Work triangle, each leg | 1.2-2.7 m / 4-9 ft | guideline |
| Work triangle, total | ≤ 7.9 m / 26 ft | guideline |
| Landing beside the cooktop | 0.30 m one side, 0.38 m other (12 / 15 in) | guideline |
| Landing beside the sink | 0.61 m one side, 0.46 m other (24 / 18 in) | guideline |
| Landing at the fridge handle side | 0.38 m / 15 in | guideline |
| Main prep counter | ≥ 0.91 m wide (36 in), next to the sink | guideline |
| Dishwasher to sink edge | ≤ 0.91 m / 36 in | guideline |
| Counter to the underside of the uppers | 0.46 m / 18 in typical | guideline |
| Cooktop to range hood | 0.61-0.76 m / 24-30 in; the hood's manual wins | guideline |
| Pendant bottom over an island or table | 0.76-0.91 m / 30-36 in above the top | taste |

Island test: an island needs the aisle numbers on **every working side**. A useful island starts
at about 0.6 × 1.2 m (24 × 48 in). If both rules can't be met, say so and offer the no-island
answer: a peninsula, a wider run, or a table.

## Light level when swapping fixtures

In roomkit units a ~800 lm bulb is ~360 W. A shaded or downward fixture puts most of that on the
table, while an open flush mount lights the ceiling and walls as well. Match what the old fixture
put into the room, or the "after" is brighter only because of the bulb. Under-cabinet strips add
task light without changing the overall level much.
